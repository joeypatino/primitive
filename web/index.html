Primitive Pictures

Reproduces an image one shape at a time, keeping each shape only if it brings the picture closer to the original. This is the Go package from joeypatino/primitive compiled to WebAssembly, running on several threads in this tab.

-i

Or drop an image on the canvas.

-m
